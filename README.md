# OrthoCare - Clinical & Orthopaedic Specialist Website

OrthoCare is a modern, responsive, and search-optimized Next.js web application built for orthopaedic clinics and orthopedic doctors. It provides comprehensive sections to showcase treatments, details on orthopaedic diseases, news & activities, and online tele-consultation booking features.

## 🚀 Key Features
- **Modern Tech Stack**: React 18+, Next.js 15+, Bootstrap 5, and Sass/SCSS.
- **Service Pages**: Comprehensive treatments list & details.
- **Interactive Forms**: Appointment and tele-consultation request system.
- **Dynamic SEO**: Customized metadata for optimal search engine performance.
- **Responsive Layout**: Designed for all device viewports.

## 🛠️ Tech Stack & Setup
- **Framework**: React & Next.js
- **Styling**: Vanilla CSS + SCSS
- **Utility & Grid**: Bootstrap 5

### Commands

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run local development server:
   ```bash
   npm run dev
   ```

3. Build production application:
   ```bash
   npm run build
   ```

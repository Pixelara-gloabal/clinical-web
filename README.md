# Clinic Web

A clean, modern React & Next.js website for medical practices and healthcare clinics.

## Getting Started

First, install the dependencies if you haven't already:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `components/` - React components
- `pages/` - Next.js pages
- `public/` - Static assets (images, fonts)
- `styles/` - Global CSS stylesheets
- `assets/` - Theme configurations and SCSS files
- `hooks/` - Custom React hooks
- `plugins/` - Custom plugins
- `theme/` - Theme provider and options
